## Ezra's Stremio 2.1.0 Beta 1

- **Manage lists.** Rename, reorder, delete, and choose which lists appear on Home from the Library toolbar.
- **Import and export list membership.** Backups include custom lists and manual Anime or Live Action choices. Preview an import before merging it with your Library lists. A conflicting manual category keeps its current assignment.
- **Picture and playback settings.** Select Anime4K or FSR, control border blur and framing, and see when mpv confirms a shader selection. Save audio and subtitle languages and optional shader and framing preferences for a series on this device.
- **Change source.** Reopen the source picker for the current episode or movie. Choose whether to resume near your previous position on the replacement stream.
- **Playback diagnostics.** Copy recent buffering events, shader shortcut timings, dropped frame counts, and renderer details from the Picture panel. The report contains no stream links or account credentials.
- **Version and Windows launch fixes.** Settings shows the Ezra's Stremio version beside the other version numbers. Windows startup preserves accented and non-Latin characters in local filenames.

Custom lists and manual corrections are stored per account on each Windows device. On another computer, Anime and Live Action rebuild from your regular Stremio Library.
