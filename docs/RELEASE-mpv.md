## Ezra's Stremio 2.0.0 Beta 5

- **Faster interface preparation at startup.** The app checks only the parts of the hosted script where Library hooks can begin. It still validates each match and skips custom list hooks if the interface changes or a match is ambiguous.

Custom lists and manual corrections are stored per account on each Windows device. On another computer, Anime and Live Action rebuild from your regular Stremio Library.
