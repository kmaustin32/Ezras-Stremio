## Ezra's Stremio 3.0.0 Beta 1

- **Local Profile & Search** opens without a Stremio account or hosted web page. Open it from the Windows tray or the Library backup section of Settings.
- **Encrypted folder sync** supports a folder you choose in Google Drive for desktop, OneDrive, another desktop sync service, or a local drive. Set up the same folder and passphrase on each PC. The local copy remains accessible if the folder goes offline.
- **Account recovery** can copy your Stremio library, available watch progress, custom lists, and configured add-ons while signed in. It can also import `Backup.json` from an existing Ezra's Stremio backup without an account.
- **Catalog search** looks up movies and shows through supported add-ons, with Cinemeta and an independent TMDB Addon available. The bundled screen can play direct HTTP and HTTPS links that do not require custom proxy headers.

The beta copies data from Stremio into your local profile. Edits in the local profile sync through the selected folder. If the hosted interface loads but Stremio sign-in or its account service is unavailable, use **Local Profile & Search** from the tray. The regular Stremio interface remains available from the local screen.
